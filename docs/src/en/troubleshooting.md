# Troubleshooting

## Before you report

- If a document is missing, wait until the job tray shows that processing has finished.
- If a page fails to load, reload it and sign in again.
- Check the [FAQ](faq.md).

## Reporting a bug or requesting a feature

Search the existing issues at <https://github.com/dfki-ebls/hivegent/issues>, then open a new one if needed.

## Helping us reproduce the problem

Describe what you did, what you expected, what happened instead, the exact error or a screenshot, and your browser.

If the problem concerns a conversation, export it as JSON and attach the file.
The export contains the messages, tool calls, and documents used, so remove anything confidential first.
