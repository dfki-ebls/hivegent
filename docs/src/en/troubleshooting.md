# Troubleshooting

## Before you report

Many issues clear up on their own.

- If the assistant cannot find a document, wait until the job tray in the top bar shows that processing has finished.
- If a page fails to load, reload it and sign in again.
- Check the [FAQ](faq.md) for common questions about accuracy, formats, and access.

## Reporting a bug or requesting a feature

Bug reports and feature requests are handled on GitHub.

- Open an issue at <https://github.com/dfki-ebls/hivegent/issues>.
- First search the existing issues, so you can add to a related report instead of opening a duplicate.
- Describe what you expected, what happened instead, and the steps to reproduce it.

## Helping us reproduce the problem

The more context you include, the faster an issue can be resolved.

A good report contains:

- What you did and what you expected to happen.
- The exact error message or a screenshot.
- Roughly when it happened and which browser you used.

If the problem concerns a specific conversation, export it and attach the downloaded file to the issue.
Open the conversation, use the export button to download it as a JSON file, and add that file to your report.
It captures the messages, the tools the assistant used, and the documents it pulled in, which gives us the context needed to reproduce the behavior.

Please remove anything confidential before sharing an export, since it includes the conversation content.
