# Einleitung

</div>

Hivegent ist ein selbst gehosteter Assistent, der Fragen zu Ihren eigenen Dokumenten beantwortet.
Sein Agent durchsucht, liest und durchdenkt die hochgeladenen Dateien und gibt die verwendeten Quellen an.

## Was Sie tun können

- Mit Ihren Dokumenten chatten und Antworten mit Quellenangaben erhalten.
- PDFs, Office-Dateien, Bilder und mehr hochladen, die Hivegent umwandelt und indexiert.
- Dokumente in einem privaten und in geteilten Gruppen-Arbeitsbereichen ablegen.
- Den Agenten in mehreren Schritten arbeiten, bei Aktivierung im Web suchen und sich Kontext über Unterhaltungen hinweg merken lassen.
- Ihren Editor oder andere Werkzeuge über das Model Context Protocol (MCP) anbinden.

## Unterschied zu einem einfachen Chatbot

- Aktuell: Antworten stützen sich auf Ihre neuesten Dokumente, nicht nur auf Trainingswissen.
- Belegt: Jede Antwort kann auf die Textstelle verweisen, aus der sie stammt.
- Agentisch: Der Assistent wählt Werkzeuge und sucht in mehreren Schritten.
- Privat: Ihre Dokumente bleiben auf Ihrer eigenen Infrastruktur.
