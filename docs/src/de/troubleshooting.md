# Fehlerbehebung

## Bevor Sie melden

Viele Probleme lösen sich von selbst.

- Findet der Assistent ein Dokument nicht, warten Sie, bis die Aufgabenleiste in der oberen Leiste die Verarbeitung als abgeschlossen anzeigt.
- Lädt eine Seite nicht, laden Sie sie neu und melden Sie sich erneut an.
- Sehen Sie in der [FAQ](faq.md) nach häufigen Fragen zu Genauigkeit, Formaten und Zugriff.

## Einen Fehler melden oder eine Funktion vorschlagen

Fehlerberichte und Funktionswünsche werden auf GitHub bearbeitet.

- Öffnen Sie ein Issue unter <https://github.com/dfki-ebls/hivegent/issues>.
- Durchsuchen Sie zuerst die vorhandenen Issues, damit Sie zu einem verwandten Bericht beitragen, statt ein Duplikat anzulegen.
- Beschreiben Sie, was Sie erwartet haben, was stattdessen geschah und wie sich das Problem reproduzieren lässt.

## Uns beim Nachstellen des Problems helfen

Je mehr Kontext Sie angeben, desto schneller lässt sich ein Problem lösen.

Ein guter Bericht enthält:

- Was Sie getan und was Sie erwartet haben.
- Die genaue Fehlermeldung oder einen Screenshot.
- Ungefähr wann es geschah und welchen Browser Sie genutzt haben.

Betrifft das Problem eine bestimmte Unterhaltung, exportieren Sie sie und hängen Sie die heruntergeladene Datei an das Issue an.
Öffnen Sie die Unterhaltung, laden Sie sie über die Export-Schaltfläche als JSON-Datei herunter und fügen Sie diese Ihrem Bericht bei.
Sie enthält die Nachrichten, die vom Assistenten genutzten Werkzeuge und die herangezogenen Dokumente und liefert damit den Kontext, der zum Nachstellen des Verhaltens nötig ist.

Bitte entfernen Sie vor dem Teilen alles Vertrauliche aus einem Export, da er den Inhalt der Unterhaltung enthält.
