# Fehlerbehebung

## Bevor Sie melden

- Fehlt ein Dokument, warten Sie, bis die Aufgabenleiste die Verarbeitung als abgeschlossen anzeigt.
- Lädt eine Seite nicht, laden Sie sie neu und melden Sie sich erneut an.
- Sehen Sie in der [FAQ](faq.md) nach.

## Einen Fehler melden oder eine Funktion vorschlagen

Durchsuchen Sie die vorhandenen Issues unter <https://github.com/dfki-ebls/hivegent/issues> und eröffnen Sie bei Bedarf ein neues.

## Uns beim Nachstellen des Problems helfen

Beschreiben Sie, was Sie getan und erwartet haben, was stattdessen geschah, die genaue Fehlermeldung oder einen Screenshot und Ihren Browser.

Betrifft das Problem eine Unterhaltung, exportieren Sie sie als JSON und hängen Sie die Datei an.
Der Export enthält Nachrichten, Werkzeugaufrufe und genutzte Dokumente, entfernen Sie daher vorher alles Vertrauliche.
